This mod bundles a single interop source file from the "UI Fixes" project:

    File:    MultiSelectInterop.cs  (in the Leaves-GuildStash-Client plugin)
    Source:  https://github.com/tyfon7/UIFixes  (tag v5.3.11)
    Purpose: optional, reflection-based hook into UI Fixes' multi-select feature
             so several guild boxes can be opened/closed at once. UI Fixes is a
             soft dependency - Guild Stash works without it.
